# Security reports

This is a private development repository. Report security findings privately
to the repository owner through an existing trusted channel; do not post keys,
pairing codes, browser profile data, full page contents or authenticated URLs
in issues, logs or screenshots.

No production version is currently supported. Development pairing is separate
from production release trust. A successful handshake is not permission to
enable capabilities outside the negotiated and server-approved scope.

Before public distribution, configure a public security contact and private
vulnerability reporting. Public disclosure and response policy remain release
gates, not invented contact information.
